# Sideloader-Source
My apps source on Sidestore, AltStore, LiveContainer, and other sideloading marketplaces.

## Steps to add to sideloading marketplace
1. Copy `https://pixel-guys-projects.github.io/Sideloader-Source/source.json`.
2. Open marketplace, go to Sources, and paste the source in the new source field.
3. Done, install any app you want,
